# 03｜细节

## 1. 什么是细节

**细节不是写得多，而是写得准**。

细节描写真正厉害的地方，不在于把一个人从头发丝写到鞋底，而在于抓住那个最能代表他、最能让人一下看到他的地方。

## 2. 为什么细节重要

读者记住人物，往往不是记住"她很漂亮""他很沉稳""这间屋子很旧"。

读者记住的是：

- 她紧张时总爱捏袖口
- 他写字时会把纸角折出一道小三角
- 某人笑起来太快，连肩膀都会跟着晃

**这才是细节**。细节一准，人物就立住了。

## 3. 细节应该抓什么

### 抓动作特征

比起抽象评价，动作更能说明人。

❌ 空写：某人很稳

✅ 实写：他把卷子一摞一摞往下分，到最后一排时都没让纸边散一下

### 抓局部特征

人物不是靠五官说明书立起来的，而是靠一两个**高辨识度的局部**。

常用局部：眼角、手指、鞋尖、刘海、袖口、随身物件、说话时的嘴角动作

### 抓习惯性反应

人物最值钱的细节，不是偶然一次动作，而是**重复出现的习惯**。

例子：
- 角色 A 一紧张就会把手缩进袖子里
- 角色 B 被逼急时反而更安静
- 角色 C 每次想岔开严肃气氛，都会先抛一个夸张玩笑

**这种细节反复出现，人物就会越来越真**。

## 4. 细节描写的使用方法

### 方法一：先找关键词，再找细节

写一个人之前，先问自己：**如果只用一个词形容他，我会选什么**？

然后围绕这个词去找最能体现它的细节。

例子：

- 关键词"压抑"：不一定写他说自己压抑——可以写他把笔记本压回抽屉最里层
- 关键词"克制"：不一定写他很克制——可以写他明明站得很近，却始终没碰到她的手
- 关键词"冷漠"：不一定写他冷漠——可以写他听完一段长长的求情，回了一个字"嗯"

### 方法二：让细节服务情绪

细节不是摆设，是拿来推动人物情绪的。

一个细节最好至少起一个作用：

- 立人物
- 推气氛
- 暗示关系
- 埋伏笔

如果一个细节什么作用都没有，它可以删。

## 5. 常见问题

### 问题一：细节写成说明书

**症状**：从头写到脚 / 什么都交代 / 结果没有重点

**解决方法**：只保留最有表现力的 1-3 个细节。

### 问题二：只会用形容词

**症状**：漂亮 / 可爱 / 高大 / 悲伤——这些词本身不产生画面。

**解决方法**：别急着下定义，先找**动作**、**局部**、**习惯**。

### 问题三：细节没有归宿

**症状**：很用力写了一个细节，但全章读完发现它没起任何作用

**解决方法**：写细节前先问"这个细节为情绪 / 关系 / 伏笔做什么贡献"。

## 6. 题材适配建议

| 角色类型 | 适合突出哪类细节 |
|---------|---------------|
| 内向 / 压抑型 | 小动作、停顿、眼神回避、手指动作 |
| 稳重 / 克制型 | 做事时的稳定感、沉默时的细节、压住情绪的动作 |
| 活泼 / 急性子 | 节奏快、动作轻快、表情变化大 |
| 高冷 / 少话型 | "少但准"的动作和说话方式 |
| 反派 / 心机型 | 表情和动作之间的微小不同步 |
| 老者 / 沧桑型 | 习惯性手部动作（搓手 / 摸物件） |
