# 02｜感官

> **适用边界**（先读这里，别生搬硬套）
> - 网文适配：**慎用**——五感堆砌是网文拖节奏、"水字数"的重灾区；只在关键节点点 1-2 感即可。
> - 最搭题材：传统/严肃文学、言情、氛围向、美食/旅行等以体验为主体的题材。
> - 慎用场景：快节奏爽文、信息推进段、打斗段——每段全五感 = 读者弃书。

## 1. 什么是感官描写

感官描写，就是把人物"看见、听见、闻见、尝到、碰到"的东西写出来。

常见五感：视觉、听觉、嗅觉、味觉、触觉。

画面感强，不只是因为看见了什么，更因为读者会"跟着人物一起在场"。

## 2. 为什么感官重要

很多写作发空，不是因为情节弱，而是因为人物像飘在半空里，没真正落到世界上。

感官一进来，场景就落地了。

比如"她很喜欢他"这句话很空。

但如果你写：

- 她听见他从远处说话，明明没叫自己，还是下意识抬头
- 风吹过来，带着他身上淡淡的汗味和某种洗衣液味道
- 他把东西递过来时，纸边擦过她指尖

这时候就不需要直接说"她很喜欢他"，读者自己会感觉到。

**口诀**：情绪不要说出来，让感官去说。

## 3. 五感的具体用法

### 视觉

最常用，但不要只写"看见了什么"，要写"看见什么最扎眼"。

❌ 空写：场地很热闹

✅ 实写：场地中央的灯光被汗水折射出几条亮线，远处有人挥手叫喊，喊声被人群裹住，听不清在叫谁

### 听觉

听觉特别适合营造空间感。任何场景本来都是有声音层次的：

- 远处持续的背景音（车流 / 人声 / 风 / 雨）
- 中距离的人为声音（说话 / 脚步 / 物件碰撞）
- 近距离的细微声音（呼吸 / 衣料摩擦 / 笔尖）

听觉一进来，空间感就出来了。

### 嗅觉

嗅觉是**最容易被忽视**但**最能唤起情绪和记忆**的感官。

通用例子：
- 雨后泥土味
- 旧书页的霉墨味
- 食物味（饭菜、烟草、酒、香水）
- 季节性气味（栀子花、桂花、雪后空气、夏天柏油路）
- 人的体味（汗味、洗发水味、淡香水味）

嗅觉尤其适合写"回忆"和"亲密感"。

### 味觉

味觉不一定只用于吃饭场景，也可以用来加强生活气和当下感。

通用例子：
- 茶/咖啡/酒入口的瞬间
- 冰棒、糖果化开
- 嘴里的苦味、铁锈味（紧张 / 受伤）
- 某种食物意外让人想起的久远回忆

### 触觉

触觉很适合写**紧张**和**亲密**。

通用例子：
- 指尖碰到物件边缘
- 风从某个开口灌进来掠过皮肤
- 衣料对皮肤的摩擦
- 温度（冷、烫、温存）
- 物件残留的体温

## 4. 感官使用原则

### 原则一：按场景需要调用

不是每一段都要五感全开。

有时候只需要：视觉 + 听觉
有时候只需要：嗅觉 + 触觉

**关键不在于多，而在于准**。

### 原则二：感官要跟人物当时的心理一致

同样一场雨，不同心情的人会感受到不同的东西。

- 心动时，会注意到雨声、体温、伞沿滴水
- 焦虑时，会觉得鞋底发滑、袖口发黏、空气闷得透不过气
- 悲伤时，可能只看到水珠从车窗一路滑下，听不见任何声音

**口诀**：感官不是装饰，是人物情绪的外延。

## 5. 常见问题

### 问题一：为了画面感把所有感官都写一遍

**症状**：啰嗦 / 像完成任务 / 读者一看就觉得刻意

**解决方法**：写完一段后问自己——这一段里，人物**最先**感受到的到底是什么？保留最有用的 1-2 个感官就够了。

### 问题二：感官和情绪脱节

**症状**：人物明明很难受，环境却被写得很闲适 / 人物明明很开心，场景却老是压抑发灰

**解决方法**：先确定人物当下情绪，再决定哪些感官应该被"打开"、哪些应该"关闭"（情绪极度集中时，其他感官会暂时失效——这是真实的）。

## 6. 题材适配建议

| 场景类型 | 推荐感官组合 |
|---------|------------|
| 日常 | 视觉 + 听觉 |
| 暧昧 / 亲密 | 触觉 + 嗅觉 |
| 回忆 / 怀旧 | 嗅觉 + 视觉 |
| 紧张 / 压力 | 听觉 + 触觉 |
| 战斗 / 动作 | 触觉 + 听觉（疼痛 + 呼吸） |
| 悬疑 / 异常 | 听觉 + 嗅觉（"哪里不对"的感觉） |
