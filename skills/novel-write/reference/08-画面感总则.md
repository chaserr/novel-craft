# 08｜画面感总则

> **适用边界**（先读这里，别生搬硬套）
> - 网文适配：**按需**——自查清单通用，但"画面感"本身在极快节奏爽文里权重下调，别当每章硬指标。
> - 最搭题材：氛围向、传统文学、言情；爽文只做底线自查，不追求满屏画面。
> - 慎用场景：把"画面感达标"当成拖慢推进的理由——网文先保节奏与信息，画面是调味。

> 写一章前的 5 问 + 写一章后的自查清单。
> 这一章是 01-07 的**用法集成**，不引入新方法论。

## 1. 一句话目标

让文字有画面感，**不再只停留在"把事情说清楚"**。

画面感不是靠堆形容词，也不是靠空洞抒情，而是靠四种能力**配合**：

```
运镜  ×  感官  ×  细节  ×  心理
```

这四项**不是每次都要同时用满**，但每写一章，**至少要有 1-2 项是明确在线的**。

## 2. 写一章前的 5 问

写一章前，把这 5 个问题在脑子里 / 草稿里答完，再下笔。

1. **画面**：这章最该突出的画面是什么？
2. **运镜**：这章最适合用哪种运镜（参考 [01](./01-运镜.md)）？
3. **感官**：这章最该调用哪 1-2 个感官（参考 [02](./02-感官.md)）？
4. **心理**：这章里谁的心理最重要，准备借什么东西映出来（参考 [04](./04-心理.md)）？
5. **场景**：这章的关键场景更需要"细、顺、悬、张"中的哪两个（参考 [05](./05-场景四字诀.md)）？

## 3. 写章节时的模板

| 维度 | 这一章我打算怎么做 |
|------|-----------------|
| 运镜 | 先拍哪里，再拍哪里 |
| 感官 | 这一段最该让读者**闻到 / 听到 / 碰到 / 看到**什么 |
| 细节 | 这一章哪个动作或局部最能代表人物状态 |
| 心理 | 这场戏真正要传达的情绪是什么，用什么场景去映它 |
| 场景 | 这一场先靠"细 + 顺"立住，还是先靠"悬 + 张"发力 |
| 章末 | 用 [07](./07-章末结构.md) 哪种章末结构？避免连续同款 |
| 信息密度 | 哪几段需要按 [06](./06-信息密度.md) 紧一紧 |

## 4. 如果你写不出画面感

**先别急着加形容词**。

先停下来问自己：

- 镜头现在拍得**顺不顺**
- 人物到底**看见了什么、听见了什么**
- 有没有一个**真正能记住的细节**
- **场景和心理**是不是咬在一起
- 这一段**有没有一点悬念或张力**
- 场景**推进**到底顺不顺

画面感不是"写得花"，而是"**让读者真的看见**"。这才是关键。

## 5. 写完一章的自查清单

逐项过一遍：

- [ ] 有没有明确的**场景中心**
- [ ] 有没有至少一个**关系变化点**
- [ ] 有没有至少一个**人物内心变化点**
- [ ] 章尾**钩子**是否清晰（A / B / C 级，不能 D）
- [ ] 章末结构**和上一章不同款**
- [ ] 整章读完是否有**可以立住的画面**（不只是说清楚了事情）
- [ ] 整章至少有 1-2 项（运镜 / 感官 / 细节 / 心理）**明确在线**
- [ ] 没有连续 5 句以上同句长（节奏混搭）
- [ ] 没有出现 [zh-novel-polish](../../zh-novel-polish/SKILL.md) 病灶一（命名式情绪复述）

任何一项答 ✗ → 回去改。

## 6. 与 zh-novel-polish 的分工

| 阶段 | 谁负责 |
|------|-------|
| 写初稿时**主动**调用四件套 + 章末 + 信息密度 | **本 reference** |
| 写完初稿后**被动**扫病灶并修复 | [zh-novel-polish](../../zh-novel-polish/SKILL.md) |

也就是说：本 reference 教你**怎么写**，zh-novel-polish 教你**怎么修**。
两者互补，缺一不可。
