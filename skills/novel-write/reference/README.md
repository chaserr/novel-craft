# novel-write reference

> 长篇小说写作的通用技法 reference。**题材中性**，校园青春、悬疑、武侠、科幻、历史、都市均适用。

`novel-write` 在生成初稿前会按需查阅以下文档。其中：
- 01-06 是**画面感**的核心四件套 + 综合用法（运镜、感官、细节、心理、场景四字诀、信息密度）
- 07 处理**章末结构**（章节钩子的多样化）
- 08 是写一章前的**自查清单**

题材专属技法（例如校园的"楼梯转角符号"、武侠的"江湖切口"等）由项目自己在 `写作技巧/` 目录下积累，不属于本 reference。

## 使用原则

- **不要每写一段都四件套全开**——按场景需要调用 1-2 项
- **不要把 reference 当公式**——它是写作时回头检查的视角，不是必须照搬的模板
- **项目专属技法优先级 ≥ reference 通用技法**——`项目目录/写作技巧/*.md` 里如果有项目自己沉淀的方法，应当**优先**采用
