# novel-write reference

> 长篇小说写作的通用技法 reference。**题材中性**，校园青春、悬疑、武侠、科幻、历史、都市均适用。

`novel-write` 在生成初稿前会按需查阅以下文档。其中：
- 01-06 是**画面感**的核心四件套 + 综合用法（运镜、感官、细节、心理、场景四字诀、信息密度）
- 07 处理**章末结构**（章节钩子的多样化）
- 08 是写一章前的**自查清单**
- 09 处理**期待值管理**（情节尺度上怎么持续吊着读者）
- 10 是**情绪控制力**（网文的"骨头"——情绪前置 / 落差 / 锚点，其余全是手段）

题材专属技法（例如校园的"楼梯转角符号"、武侠的"江湖切口"等）由项目自己在 `写作技巧/` 目录下积累，不属于本 reference。

## 适用边界与题材适配（防生搬硬套）

> **每篇技法都有边界，不是全书全场景通吃。** 每个文件顶部都有一个「适用边界」块，
> **读某篇前先读它那三行**，判断这篇技法适不适合当前题材 / 节奏，再决定用不用、用多少。

### 纲领：网文 ≠ 传统文学

- **网文**（连载 / 爽文 / 升级流 / 都市）：**节奏、爽点、信息效率优先**，画面感是调味不是主菜。默认**别把 01/02/04/08 当每段必用**——五感堆砌、大段心理、慢镜头是网文"水字数、拖节奏"的三大重灾区。
- **传统 / 严肃文学、氛围向、言情**：画面、心理、感官**可以作为主体**，四件套开得更满是加分。
- AI 落笔前先问一句：**这本书是什么题材、这一段是什么节奏？** 再挑技法，绝不 01-09 一律全开。

## 使用原则

- **先读适用边界，再决定用不用**——技法不匹配题材/节奏时，宁可不用
- **不要每写一段都四件套全开**——按场景需要调用 1-2 项
- **不要把 reference 当公式**——它是写作时回头检查的视角，不是必须照搬的模板
- **项目专属技法优先级 ≥ reference 通用技法**——`项目目录/写作技巧/*.md` 里如果有项目自己沉淀的方法，应当**优先**采用

## 新增技法的审核 + 标注流程（强制）

**每新增一篇技法（0X-xxx.md），必须走完以下四步，缺一不可：**

1. **审核适用性**：这条技法适合网文吗？适合哪些题材？在什么节奏下会翻车？想清楚再写。
2. **文件顶部加「适用边界」块**（H1 下方，正文之前），固定三行：
   ```
   > **适用边界**（先读这里，别生搬硬套）
   > - 网文适配：**核心 / 按需 / 慎用**——<一句为什么>
   > - 最搭题材：<...>
   > - 慎用场景：<...>
   ```
   网文适配三档：**核心**=网文必用 / **按需**=看题材与节奏 / **慎用**=易拖节奏或文艺腔，仅特定题材用。
3. **登记三处**：本 README 的「目录」表 + 「速查表」各加一行；`../SKILL.md` 第 37 行的 reference 清单补上编号。
4. **文末补「题材适配建议」小节**（可选但推荐），展开分题材的用法差异。

> 未加「适用边界」块、未登记进速查表的技法，视为**未完成**，不得并入 reference。
