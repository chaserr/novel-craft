# 04｜心理

> **适用边界**（先读这里，别生搬硬套）
> - 网文适配：**按需**——网文忌大段内心独白（慢、"水"）；本篇教的"借环境/动作/节奏写心理"正是网文友好的做法。
> - 最搭题材：情感、成长、严肃文学；爽文用其"动作代心理"的部分，不用大段独白。
> - 慎用场景：爽文的推进/爽点段——心理让位给动作和对话，读者要的是"做了什么"。

## 1. 什么是心理描写

**心理描写不等于把人物内心话全说出来**。

真正高级的心理描写，很多时候不是直接写"她很难过""他很紧张"，而是通过：

- 环境
- 动作
- 感官
- 节奏

把人物的心理**映出来**。

## 2. 为什么心理决定画面感

写景如果跟人物情绪没有关系，往往只是漂亮。

只有当场景和人物心理互相咬合，画面才会真正有力度。

比如同一条走廊：

- 心动时，风是轻的，光是亮的，脚步声都变得清楚
- 焦虑时，风会变成闷，铃声会变成刺耳，整条走廊像压得人喘不过气

**不是走廊变了，是人物的心理在改变读者看见这条走廊的方式**。

## 3. 心理描写的常见做法

### 方法一：借环境映心理

这是最实用的一种。

人物的心理不一定要直说，可以借**天气 / 光线 / 声音 / 空间 / 物体状态**去折射。

例子：

- 心里悬着事 → 风把窗帘一下一下掀起来，总也不安稳
- 情绪快崩 → 笔尖戳破纸，字写不成行
- 久别重逢 → 屋里所有声音都退到很远，只听见自己心跳

### 方法二：借动作漏心理

人越想藏，动作越容易露。

例子：

- 嘴上说没事，手却把杯壁捏出指印
- 表面平静，喝水时喉结却动得很急
- 假装没听见，但脚步停了一拍

### 方法三：借节奏写心理

心理变化不只是内容，也在句子节奏里。

- 紧张时，句子可以短一点、急一点
- 失落时，句子可以慢一点、松一点
- 心动时，句子可以在细节处稍微停留
- 麻木时，句子可以平铺，没有起伏

### 方法四：借"空白"写心理

什么都不写也能写心理。

- 角色被告知一个噩耗——下一段直接切到他第二天上班，什么反应都没写
- 这种"留白"本身就是巨大的心理表现

## 4. 核心原则

### 原则一：不要只会"解释心理"

❌ 直白：
- 她很难受
- 他特别紧张
- 她非常委屈

这些可以写，但**不能只写这些**。要让读者自己感到难受、紧张、委屈。

### 原则二：画面要和心理一致

你想写轻松，就不要硬配萧条的景。
你想写压迫，就不要把场景写得太云淡风轻。

心理和画面如果打架，读者会出戏。

### 原则三：不要在心理描写里停滞过久

每段心理描写最多停留**一两段**，就要回到动作或对话。
心理描写连写 3 段以上 = 读者开始走神。

## 5. 常见问题

### 问题一：心理全靠独白撑

**症状**：连续大段内心分析 / 情绪说得很明白，但读者感受不到现场

**解决方法**：把一半心理删掉，换成环境、动作、感官。

### 问题二：心理没有层次

**症状**：一上来就是"崩溃""痛苦""难过" / 情绪没有铺垫，像直接拉满

**解决方法**：先从**轻微的不对劲**开始，再慢慢加深。情绪需要爬坡。

### 问题三：用"她忽然意识到……"复述前面的场景

**症状**：写完一个细致的场景后，再用一句独白把场景的"含义"说出来

**解决方法**：直接删整段独白。前面场景写好了不需要解释；前面没写好就回去改前面。详见 [zh-novel-polish 病灶一](../../zh-novel-polish/SKILL.md)。

## 6. 题材适配建议

| 角色 / 情绪类型 | 推荐表达方式 |
|--------------|------------|
| 内向 / 压抑型主角 | 多借环境和停顿写，不要让 TA 总是自我分析 |
| 沉默 / 克制型 | 多借动作和沉默写，不要让 TA 说太多 |
| 关系裂痕 | 多用空间感和对话断裂去写 |
| 压力场景（家庭/职场/学业） | 多用具体物件（饭桌、房门、灯光、手机震动、空气闷感） |
| 爆发瞬间 | 用极短的句子 + 单一感官（只听见一个声音 / 只看到一个画面） |
| 麻木期 | 用平铺直叙、无情绪起伏的句子 |
