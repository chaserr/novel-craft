# 06｜信息密度

> **适用边界**（先读这里，别生搬硬套）
> - 网文适配：**核心**——全题材通用，网文尤其吃（快、爽、一句一信息、忌"水"）。
> - 最搭题材：全部，网文优先级最高。
> - 慎用场景：极少数需要"故意放慢、留白呼吸"的抒情段——此时可短暂降密度，但别成常态。

> 信息密度高的文字读起来"有嚼劲"。信息密度低的文字读起来"水"。这一章三件事。

## 1. 删掉多余的形容词和副词

把稿子里的「的」和「地」标出来，尝试删掉一半。大多数情况下，删掉之后句子反而**更有力量**。

| ❌ 弱 | ✅ 强 |
|------|------|
| 他愤怒地看着我 | 他瞪着我 |
| 她小心翼翼地端起杯子 | 她端起杯子 |
| 天空湛蓝湛蓝的 | 天很蓝 |
| 一个非常巨大的、有些破旧的建筑 | 建筑很大，看得出有年头 |
| 他重重地、用力地、一拳砸在桌上 | 他一拳砸在桌上 |

**原则**：副词每减一个，动词就强一分。

## 2. 用动作代替状态

新手常写抽象状态，但读者难以感知。用具体动作替代，会更生动。

| ❌ 抽象状态 | ✅ 具体动作 |
|----------|------------|
| 他很紧张 | 他不停搓手，指节都发白了 |
| 她很开心 | 她笑得眼睛弯成了月牙 |
| 气氛很压抑 | 没人说话，只有空调嗡嗡响 |
| 他很愤怒 | 他攥着拳头，骨头在皮下凸起 |
| 她很犹豫 | 她伸手又收回，走了两步又停下 |
| 他很疲惫 | 他坐下时，椅子被压得轻轻一响 |

**口诀**：先写动作，再决定要不要补一句状态——多数时候不需要。

## 3. 一个句子只传递一个信息

避免在一个句子中塞入过多信息。拆分为短句，**更清晰、有节奏**。

### 反例：信息塞满

> 他推开门，看到屋里一片狼藉，桌椅翻倒，地上散落着文件，窗户大开，窗帘被风吹得猎猎作响，显然有人来过。

### 修后：一句一信息

> 他推开门，愣住了。
> 屋里一片狼藉，桌椅翻倒，文件散落一地。
> 窗户大开着，窗帘被风吹得猎猎作响。
> 有人来过。

短句更有节奏感，也更容易读。

### 加分技巧：节奏混搭

短句一直短 = 像念清单
长句一直长 = 像憋着

理想：**短-长-短** 或 **长-短-短-长**，制造呼吸感。

## 4. 进阶：用一个细节替代一段背景

如果你要写一个人的处境，**先别用一段总结**——找一个能浓缩这件事的小事。

❌ 总结式背景：
> 她从小被父母忽视，长大后终于清醒。

✅ 一件小事承担：
> 她下班后赶到医院，母亲第一句话不是问她累不累，而是把弟弟的房贷截图递给她，说："你先把这个月的补上，手术费我们再想办法。"

那张截图，比一大段背景**更有力**。

读到这里读者已经明白：这家人长期把她当作经济来源、母亲把弟弟摆在女儿前面、女儿这次回来又被预设要"承担"。**这些都不用解释**。

### 这种写法的原理

- 一个具体场景 = 多重信息
- 一段抽象总结 = 一个被读者快速跳过的信息
- 信息密度差异，常常是一倍以上

## 5. 自查清单（写完一段后跑一遍）

- [ ] 副词数量 > 动词数量 → 删一半副词
- [ ] 一句话承担超过 3 个信息 → 拆
- [ ] 出现"很 / 非常 / 十分 / 极其 / 简直"超过 2 次 → 改具象
- [ ] 出现"地"超过 4 次 → 删一半
- [ ] 段落超过 5 句 → 分段
- [ ] 整段连续长句无短句 → 加 1-2 个短句
- [ ] 出现"……了……了……了……了" → 删一半"了"
