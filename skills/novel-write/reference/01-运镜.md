# 01｜运镜

> **适用边界**（先读这里，别生搬硬套）
> - 网文适配：**按需**——运镜要快、服务信息，不为画面而画面；快节奏爽文里长镜头/远景堆砌会拖节奏。
> - 最搭题材：氛围向、言情、悬疑、有仪式感/大场面的开场收束。
> - 慎用场景：升级流/爽文的高频打斗与信息推进段——切镜一多就"慢"。

## 1. 什么是运镜

运镜原本是电影术语。放到写作里，可以理解成一句最简单的话：

**你的笔，就是摄影机。**

你写一段场景，不是在"说明发生了什么"，而是在决定：

- 镜头先拍哪里
- 镜头离人物有多近
- 镜头接下来往哪里移
- 最后让读者看见什么

画面感强的文字，常常不是因为句子多华丽，而是因为镜头顺。

## 2. 为什么运镜重要

同样一件事，镜头顺序不同，读者感受到的情绪就完全不同。

如果你一上来就把人物、物件、背景、旁观者全部堆在一个平面里，读者虽然能看懂，但脑子里画面是散的。

如果你先给一个局部特写，再给人物动作，再把镜头拉远到环境，画面就会层层展开，读者能"看到它怎么发生"。

这就是运镜的作用：让文字变成立体的、会流动的画面。

## 3. 常见运镜方式

### 近景 → 中景 → 远景

**适合**：日常动作、具体场景、让读者先被一个小细节抓住

**写法思路**：
1. 先给局部特写
2. 再让人物进入画面
3. 最后拉到人物所处环境，形成完整场景

**通用示例**：写主角在家收到一封信
- 先写信封边角被指甲掐出的折痕
- 再写主角低头拆信时手指的停顿
- 再拉到整个房间的灯光、窗外天色和远处隐约传来的人声

### 远景 → 中景 → 近景

**适合**：离别、归乡、大型仪式、带氛围的开场或收束

**写法思路**：
1. 先铺开整体环境
2. 再把人物放进环境里
3. 最后推进到人物某个极细微的表情、动作、眼神

**通用示例**：写一场告别
- 先写站台的人流、广播、风、远处列车进站的轰鸣
- 再写两个人站在人群中间
- 最后给一个手指捏着对方衣袖的小动作

### 中景切近景

**适合**：对话场景、情绪突然波动、表面平静但实则有情绪的瞬间

**通用示例**：
- 先写两人并肩走在一段路上
- 再突然切到手指、喉结、眼睫、鞋尖、笔帽这类局部动作

## 4. 运镜的核心原则

### 原则一：先问自己"我要读者先看到什么"

每段场景都要有主次。不是所有东西都重要。你得先决定：

- 这一段最该先看见的是谁
- 是动作、表情、物件，还是环境

### 原则二：镜头运动要有逻辑

不能刚写眼睛，下一句突然跳到窗外，再下一句跳到鞋印，再下一句又回到嘴唇。这样不是丰富，是乱。

读者脑中的镜头如果转得太乱，画面就会散。

### 原则三：运镜为情绪服务

不是所有场景都适合拉远，也不是所有场景都适合贴脸特写。

你要表达什么情绪，就决定镜头怎么走：

- 暧昧、心动：适合近景和中景，镜头贴人物
- 孤独、失落：适合远景，人物放进环境里
- 紧张、压迫：适合中景切近景，让细节突然变得刺眼

## 5. 常见问题

### 问题一：镜头没有主次

**症状**：什么都写了一点 / 句句都像在补充说明 / 读者知道发生了什么但脑子里没有连贯画面

**解决方法**：先忘掉自己是作者，把自己当摄影师。写之前先在脑子里"看一遍"，再下笔。

### 问题二：镜头切得太快

**症状**：场景像碎片拼贴 / 气氛还没立住就跳走

**解决方法**：一段里只保留一条镜头线，不要贪多。

## 6. 题材适配建议

| 场景类型 | 推荐运镜 |
|---------|---------|
| 日常推进 | 近景 → 中景 → 远景 |
| 大型仪式 / 离别 / 命运感场景 | 远景 → 中景 → 近景 |
| 对话场景 / 暧昧 / 表面平静实则有情绪 | 中景切近景 |
| 动作戏 / 战斗 / 追逐 | 多角度快切 + 节奏短句 |
| 揭秘 / 真相 / 转折 | 近景拉特写 |
