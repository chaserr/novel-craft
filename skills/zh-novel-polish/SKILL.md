# zh-novel-polish

中文长篇小说的去 AI 味润色 skill。专注一件事：**让叙事文本读起来像真人写的小说，不像 AI 生成的散文。**

## 与一般中文润色 skill 的区别

| 一般中文 humanize | zh-novel-polish |
|------------------|----------------|
| 加入"我觉得""说实话"个人观点 | **拒绝**——叙事文不是博主文 |
| 网络词汇激活（"yyds""破防"） | 仅当角色身份/年代匹配时由作者决定，润色阶段不加 |
| 章末加"行动指引""思考方向" | **拒绝**——小说章末用悬念、未完动作 |
| 数据精确化（"增长 37%"） | **不适用** |
| 注入"专家观点"提升权威感 | **不适用** |
| 营销热词、行业黑话 | **拒绝** |

**zh-novel-polish 只做叙事文本的去 AI 化，不向任何非小说语境靠拢。**

## 开工前必读

- 项目 `RTK.md` §4（去 AI 味原则）+ §5（文风要求）+ §3.3（章节命名）
- 项目 `经典语录.md`（理解作者已认可的句式范式，不要把这种句式当病灶删）
- 至少 2 章已完成的正文（建立作者风格基线）

**不读上述资料直接润色 = 高风险**：可能把作者特意保留的风格标记当 AI 腔抹平。

## 八大叙事病灶（按出现频率排序）

### 病灶一：命名式情绪复述（致命）

写完具象动作或场景后，**紧接着用一句内心独白把刚才那场戏的"含义"说出来**。

**识别特征**：以下句式开头基本都是 AI 腔：

```
她忽然意识到 / 忽然明白 / 忽然发现，原来……
她以为……可原来……
这才是真正让她……的地方
原来……才是最让人……的
它更像 / 它其实是……
所谓 X，不过是……
```

**修复规则**：

- 一个情绪瞬间**只允许被写一次**
- 如果前面已经用动作 / 物件 / 余响 / 对白讲清楚了，**整句删除**，不留半个字
- 如果前面没讲清楚，**改写前面的动作场景去承担情绪**，而不是用独白复述

#### 原创对照样例

❌ 原文：
> 雨停了，她把伞收起来，靠在墙边。她忽然意识到，原来等一个人这么久这件事，本身已经成了答案。

✅ 修后：
> 雨停了，她把伞收起来，水珠顺着伞骨滴到鞋面。她没动。

差别：原文用一句话给了答案，读者就不需要继续想了；修后让"没动"这个动作把"答案"留在读者心里。

---

### 病灶二：长定语前置堆砌

**铁律**：名词前的修饰语不超过 **6 个字**。超过 6 个字 = 必须拆。

**拆解模板**：
- 先把名词写出来
- 再用独立短句 / 谓语描写它的状态

#### 原创对照样例

❌ 原文：
> 他推开那扇**被人涂了一层又一层不同颜色油漆已经看不出原色的**铁门。

✅ 修后：
> 他推开铁门。门面涂过一层又一层油漆，蓝盖红，红盖绿，已经看不出原色。

❌ 原文：
> 她拿起那只**外婆生前用过的、边缘磕掉一小块青瓷的**茶杯。

✅ 修后：
> 她拿起那只青瓷茶杯，外婆生前用的，边缘磕掉一小块。

---

### 病灶三："的"字过载

- **单句上限**：一个分句不超过两个"的"
- **结构禁令**：禁止 `长修饰语 + 的 + 名词`

#### 原创对照样例

❌ 原文：
> 桌上放着一杯她早上没喝完的、已经凉透了的、杯壁挂着水珠的牛奶。

✅ 修后（动词化）：
> 桌上放着一杯牛奶，她早上没喝完，已经凉透，杯壁挂着水珠。

---

### 病灶四：静态形容词主导，缺动词与感官

人类写身体感受用**动词** + **感官交互**；AI 习惯堆静态属性。

| 静态描写 | 改为动作 / 感官 |
|---------|---------------|
| 柔软的真皮沙发 | 坐进沙发，真皮陷下去，托住后背 |
| 巨大的黑板 | 黑板占满了整面墙，粉笔灰浮在光柱里 |
| 寒冷的早晨 | 推开门，冷气贴着脖子钻进衣领 |
| 温暖的灯光 | 灯亮起来，光落在桌面，照出一小圈昏黄 |

**改写口诀**：物体 + 动词 + 感官触觉 + 余响。

---

### 病灶五：连接词模板化

AI 偏爱"逻辑连接词"，叙事文本应**用场景切换和句子节奏**承担逻辑。

**删词清单**：

```
此外 / 然而 / 因此 / 综上所述 / 值得一提的是 / 不得不说
与此同时 / 一方面…另一方面
据此 / 由此可见 / 换句话说 / 由于…所以
基于此 / 在此之前 / 紧接着
```

**叙事文本的连接靠**：
- 空行（场景切）
- 同一物件 / 动作的延续（蒙太奇）
- 一句对话的回应
- 一个声音 / 气味的串场

---

### 病灶六：章末感悟收束

AI 写完一章总想"升华一下"。导致很多章结尾都长一个样：

```
事件结束 → 主角独处 → 想起一件旧事 → 一句关于成长 / 时间 / 青春的感悟
```

**zh-novel-polish 红线**：连续 3 章以上同款结尾 = 强制改写后两章。

**可替代的章末结构（按推荐顺序）**：

| # | 结构名 | 示例骨架 |
|---|--------|---------|
| 1 | 未完动作 | "她终于敲下两个字，发出去。" |
| 2 | 物件落定 | "抽屉合上时，发出一声很轻的'咔'。" |
| 3 | 跨场景叠加 | "抽油烟机响了起来，把所有可以说的话都盖在外面。" |
| 4 | 群消息切断 | "她掌心里那点没发出去的'在车上'，一直亮到屏幕自己暗下去。" |
| 5 | 一句对话未说完 | "他张了张嘴：'我其实……' 后半句被风吹走了。" |
| 6 | 未发生的事 | "她在等的人，刚才已经从另一条路走了。" |

全书允许保留 **≤ 3 处**感悟性结尾，由作者决定留给哪三章。

---

### 病灶七：对话说教化 / 完美总结化

AI 写对话喜欢让角色**把作者想说的话说出来**。这是把人物当传声筒。

#### 识别特征

- 角色说出全书主题
- 一方说完，另一方完整复述并完美回应
- 大段独白无打断、无停顿、无身体语言
- 礼貌程度超出真实情境

#### 修复方向

- 让对话**有省略、有打断、有岔开**
- 让情绪**藏在动作里**，不藏在台词里
- 让角色**说错话 / 说一半 / 转移话题**
- 长对白拆开，穿插动作、视线、环境

#### 原创对照样例

❌ 原文（说教对话）：
> "我希望你能明白，"他说，"长大是一个不断失去的过程，但失去本身也是一种获得。"
> "我懂了，"她点点头，"也许这就是青春的意义。"

✅ 修后：
> "你冷不冷？"他没回答她的问题，从书包里掏出外套。
> 她接过来披上，没说话。
> "走吧。"

差别：原文把"主题"说出来；修后把主题藏在"没回答""没说话""走吧"里。

---

### 病灶八：视角越界

第三人称限定 / 第一人称下，主角无法感知的事被写了。

**典型病例**：

- 主角在 A 房间，描写 B 房间另一个人物的表情
- 主角失去意识，仍有详细心理活动
- 第一人称里描写主角自己的"五官表情"（自己看不到自己的脸）

**修复方向**：

- 删除越界部分
- 改为间接感知（脚步声、隔墙说话声、事后才知道）
- 或建议作者切换为多视角章

---

## 通用润色清单（叙事文专属）

在处理上述八大病灶之后，再扫一遍：

| # | 检查项 | 处理 |
|---|--------|------|
| 1 | "了"字滥用 | "他走进了房间" → "他走进房间" |
| 2 | "着"字滥用 | "她拿着杯子站着" → 拆开 |
| 3 | 副词堆叠（"非常""十分""极其""特别"） | 删或改具象 |
| 4 | 同义词无意义并列（"挑战与难题"） | 留一个 |
| 5 | 翻译腔被动 | 改主动 |
| 6 | 段落超过 5 句 | 拆段 |
| 7 | 整段长句不分气口 | 加短句 |
| 8 | 章节内同一动作标签重复（"他笑了笑"） | 替换为不同动作 |
| 9 | "他说""她道"密度过高 | 部分改为动作标签 |
| 10 | "仿佛""好像""似乎"叠用 | 留一个就够 |
| 11 | 通感比喻空洞（"她的声音像云一样轻") | 改具体 |
| 12 | 数字模糊（"很久之后") | 落实到时间感（"两个学期" "三轮月考之后"） |

## 工作流程

### 输入
- 章节正文（必填）
- 项目 `RTK.md`（必读）
- 章节大纲条目（推荐）

### 步骤

1. **第一遍：建立基线**
   - 整段通读，把握情绪基调和场景目标
   - 不动笔

2. **第二遍：标记病灶**
   - 按八大病灶 + 通用清单逐处标记
   - 每个标记带病灶编号

3. **第三遍：修复**
   - 出对照版（原文 / 修后 / 修改逻辑）
   - 每处修改不超过原段意图
   - 大改动（>30%）→ **停手**，标记为"建议 novel-writer 重写"

4. **第四遍：自检**
   - 修后是否还忠于原情节
   - 修后是否破坏了人物声音
   - 修后是否影响伏笔 / 经典语录候选

5. **输出统计 + 全文性提醒**

## 输出格式

### 单处修改对照

```
【原文】第 X 段
「...」

【病灶】
- 病灶一（命名式情绪）：第 N 句
- 病灶三（"的"字过载）：第 M 句

【修后】
「...」

【修改逻辑】
- 删除"她忽然意识到……"：避免独白复述具象动作
- 拆解"挂着水珠的凉透了的牛奶"：动词化，按时间顺序展开
```

### 全章统计

```
## 本次润色统计
- 命名式情绪删除：N 处
- 长定语拆解：N 处
- 套话替换：N 处（黑名单详见 RTK §4.3）
- "的"字过载修复：N 处
- 章末结构调整：原"感悟收束" → 改"X 结构"（或：未调整）

## 全章质量自检
- 是否破坏情节：否 / 是 [说明]
- 是否破坏人物声音：否 / 是 [说明]
- 是否影响伏笔：否 / 是 [位置]
- 是否产生新的语录候选：是（N 句）/ 否

## 不擅改的疑问点
- 第 X 段「...」——疑似伏笔铺垫，请作者裁决
- 第 Y 段「...」——疑似人物声音特征，请作者裁决

## 全书级提醒（如适用）
- 高频滥用词："..."（本章 N 次，全书统计建议 novel-curator 跟进）
- 章末"感悟收束"配额：本章使用 X 次，全书剩余 (3 - 已用) 次
```

## 红线

- **绝不**在没读 RTK.md 的情况下润色
- **绝不**修改情节事实
- **绝不**改变人物关系或感情走向
- **绝不**把作者的风格标记当 AI 腔删
- **绝不**套用营销 / 短视频 / Web3 / KOL 文章的"人性化"原则
- 高质量段落（已达 `经典语录.md` 收录水平）**直接跳过**
- 改动量 > 30% → 停手，标记"建议 novel-writer 重写"
- 怀疑某处是伏笔时 → 标记疑问，不擅改

## 与其他角色协作

| 上下游 | 关系 |
|-------|------|
| **novel-write**     | 上游。zh-novel-polish 是其 §第 4 步"去 AI 味润色"的执行 skill |
| **novel-polisher**  | 平行。novel-polisher 是 agent，处理全章结构 / 风格统一；本 skill 处理单点病灶。两者可串行：先本 skill 扫病灶，再 novel-polisher 做风格统一 |
| **novel-writer**    | 当改动量 > 30% 时把球丢给 novel-writer 重写 |
| **novel-auditor**   | 发现疑似伏笔时标记不改，由 novel-auditor 核查 |
| **novel-curator**   | 全章统计的"高频滥用词"是 novel-curator 长期追踪的输入 |
