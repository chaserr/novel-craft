# 《{{书名}}》审稿报告

> `novel-review` 每批审稿后产出的报告归档于此。
> `审稿进度与问题台账.md` 累计所有未解决问题，由 `novel-curator` 定期分析。

## 文件命名

- 单批审稿：`审稿-第NN批-第X-Y章.md`
- 全书审查：`全书审查报告-YYYY-MM-DD.md`
- 累计台账：`审稿进度与问题台账.md`

## 推荐工作节奏

- 每写完 3-5 章 → 跑一次 `novel-review`（多 agent 并行）
- 每完成 3 批以上审稿 → 跑一次 `novel-curator`，提炼作者写作档案与改进路线图
- 每个幕结束 → 跑一次 `novel-architect` 做结构层审查
- 全书完稿前 → 跑一次完整全维度 `novel-review`
