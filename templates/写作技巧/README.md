# 项目专属写作技巧

> 本目录用于沉淀**项目自己**的题材专属写作技法。
> plugin 自带的通用八篇技法见 `${CLAUDE_PLUGIN_ROOT}/skills/novel-write/reference/`，已涵盖**运镜 / 感官 / 细节 / 心理 / 场景四字诀 / 信息密度 / 章末结构 / 画面感总则**——不需要在这里重写。

## 什么内容值得放在这里？

只放**通用 reference 无法覆盖**的题材专属技法。例如：

| 题材 | 项目专属技法示例 |
|------|---------------|
| 校园青春 | 楼梯转角符号库、晚自习节奏、家长会写法 |
| 武侠 | 招式编排逻辑、江湖切口、轻功镜头感 |
| 玄幻/网文 | 战力体系视觉化、突破场景的节奏、装 x 场景的边界 |
| 都市悬疑 | 雨夜镜头、电梯/地铁的悬疑符号、线索分布密度 |
| 历史/古风 | 场面调度（朝会/战阵/宴席）、礼仪写法、避讳处理 |
| 科幻 | 设定信息倾倒的节奏、技术细节的可信化、世界观信息流 |

## 优先级规则

写作时同时存在两层时：

```
项目专属（本目录）> plugin 通用（novel-write/reference）
```

也就是说：如果项目自己写了"楼梯转角符号库"，`novel-write` 就**优先**用它，不再调用通用 05 场景四字诀里的通用建议。

## 文件命名建议

```
01-<专属技法>.md
02-<专属技法>.md
...
```

## 何时增补

- 写完某章后发现**反复用到**某个题材专属技法 → 写下来
- `novel-curator` 在多轮审稿后归纳出某类**反复出现的题材问题**，给出对应解法 → 写下来
- 看了优秀同题材作品发现某种**可复用结构** → 写下来

**不要为了凑数而写**——空的更好。
